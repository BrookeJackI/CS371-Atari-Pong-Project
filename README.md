This file describes how to install/run this program and anything else the user should know.

Install Instructions
====================
- (Player A & B) Install Python onto your computer

- (Player A & B) Open Virtual Studio Code.
  Player A will open both the pongServer.py and pongClient.py.
  Player B will only open pongClient.py.

- Run the following line to install the required libraries for this project:
    `pip3 install -r requirements.txt`
  
- (Player A) Open a terminal, 'cd pong', 'py pongServer.py 5000' to run the Server

- (Player B) Open a terminal, 'py pongClient.py', a window will pop up with the pong image and 3 input

- (Player A) Open a new terminal, 'py pongClient.py', an identical window will pop up with the pong image and 3 input

- (Player A & B) Input Player A's computer IPv4, port 5000, and each player's respective initials

- (Player A & B) Click join and play to 5.

- After round 1 is over, choose to play again by clicking the space bar, or simply stop playing

- To open the leaderboard:
    1) Player running pongServer runs "py pongServer.py 5000".
    2) Terminal will say "Leaderboard page available on port 80".
    3) Go to Chrome, paste "http://localhost", and the Pong Leaderboard will appear.
